About
=====

This repo includes a simple implementation of a bi-directional Graph in C++.

Overview
--------

- It just goes over the logic of graphs through the use of a std::unordered_map<std:string, unordered_set<std::string>> as the data representaton rather than a tradtional 2D matrix.
- There also isn't weighted edges, so this rendition of a graph is VERY basic.

That is about it.
